# 배송 지연 위험 예측 및 운영 최적화 전략 — 중앙대 × 서강대 연합 해커톤 우수상(3위)

> EDA와 통계 검정으로 찾은 지연 요인을 **실행 가능한 물류 운영 전략**으로 연결한 프로젝트입니다.

## 1. 데이터

- [DataCo Smart Supply Chain](https://data.mendeley.com/datasets/8gx2fvg2k6/3) 데이터셋을 대회 측에서 정제·분할한 데이터
- 주문 180,519건 (train 144,415 / test 36,104), 피처 25개
- 타깃: `Late_delivery_risk` (1 = 지연 위험 54.8%, 0 = 정상 45.2%), 결측치 없음

| 그룹 | 주요 컬럼 |
|---|---|
| 결제·주문 | `Type`(PAYMENT / TRANSFER / DEBIT / CASH), 주문 일시, 수량 |
| 금액·수익성 | `Sales`, 할인액·할인율, 실결제액, 주문 이익, 이익률, 상품 단가 |
| 상품 | 상품명(118종), 카테고리(50종), 부서(11종) |
| 고객 | 세그먼트, 국가, 주(State), 도시, 위도·경도 |
| 주문 지리 | 시장(5), 지역(23), 국가(164), 주(1,086), 도시(3,581) |

데이터 파일은 레포에 포함하지 않았습니다 → [`data/README.md`](data/README.md)

## 2. EDA 및 가설 검정

| 가설 | 검증 | 결과 |
|---|---|---|
| **주문 시간대가 지연에 영향을 줄까?** | Chi-square (χ² = 473.94, p < 0.001) | 유의미. **낮 12시 주문의 지연 위험이 가장 높음** → 출고 마감 시각 전후로 출고일이 갈리는 구조적 병목 |
| 할인율이 높으면 주문이 몰려 지연될까? | 가격대별 할인율 × 지연율 | 대부분 가격대에서 할인율과 지연율이 비례 (특히 59.99~129.99) |
| **할인 0%인데 지연율이 높은 이유는?** | Chi-square (χ² = 8.56, p = 0.036) | **무할인·적자 주문**이 가장 높은 지연율. 할인율 0% 주문은 대부분 **Cleats**(사이즈 옵션이 많고 주문 제작 수요가 높은 품목) |
| 요일 효과가 있을까? | 요일별 지연율 | 목(55.18%)·금(55.19%)이 소폭 높음 → 주말 전 출고 집중 |
| 연휴에 지연이 늘까? | 블랙프라이데이, 연휴 D-3~당일 | 블랙프라이데이·크리스마스·추수감사절에서 유의미한 차이 (신년은 차이 없음) |
| 해외 배송이 더 늦을까? | `same_country`, `same_state` | 국가 일치 여부는 차이 미미(54.76% vs 54.84%), **주가 다르면 지연율 3.1%p 높음** → 국가보다 **주(State) 단위 물류 구조**가 중요 |

- 2018년 데이터는 1월만 존재(1,662건) → 수집 기간 종료로 판단해 이상치로 보지 않음
- `TRANSFER` 결제는 지연율 48.5%로 다른 결제 방식(56~58%)보다 낮음

## 3. 전처리 · 피처 엔지니어링

| 단계 | 내용 |
|---|---|
| 기본 정리 | `id`, `Sales` 제거 (`Sales` ≈ `Order Item Total`), 주 약어(CA, NY…) → 전체 주명 |
| 날짜 | `order_hour`, `order_month`, `order_year`, `order_weekday`, `is_weekend` |
| 로그 변환 | 상품 단가, 할인액, 실결제액, 주문 이익(음수 보정 후) `log1p` |
| 위치 | `same_country`, `same_state` (스페인어 국가·주 이름 영문 통일), **Haversine 거리** `dist_cust_to_order_region` |
| 수익·할인 | `is_loss`, `has_discount`, `profit_margin_clean`, `is_zero_discount`, `is_cleats` |
| 시간·연휴 | `is_afternoon_order`(12시 이후), `is_late_evening_order`, `is_thu_fri`, 크리스마스·추수감사절·블랙프라이데이 window (연도별 실제 날짜 계산) |
| 상품 | 상품명에서 **브랜드 19종 추출** → `brand_category`, 카테고리 10개 그룹, 가격 5구간 |
| 인코딩 | 저카디널리티: One-Hot / Label, 고카디널리티(도시·주·국가 등): **Frequency Encoding**, 결측은 중앙값 |

## 4. 모델링

### 4-1. 모델 비교 (5-Fold Stratified CV, OOF)

| 모델 | OOF PR-AUC | OOF ROC-AUC |
|---|---|---|
| **LightGBM** | **0.79593** | **0.77390** |
| 가중 평균 앙상블 (PR-AUC 기준) | 0.76411 | 0.73424 |
| 단순 평균 앙상블 | 0.75785 | 0.72712 |
| Extra Trees | 0.75692 | 0.72750 |
| 순위 평균 앙상블 | 0.73739 | 0.70476 |
| HistGradientBoosting | 0.69301 | 0.66025 |
| XGBoost | 0.67890 | 0.64407 |
| Logistic Regression | 0.58029 | 0.54357 |

→ 앙상블보다 **LightGBM 단일 모델**이 가장 높아 이후 LightGBM 중심으로 진행

### 4-2. 피처 셋 비교 (LightGBM 고정)

| 피처 셋 | 피처 수 | OOF PR-AUC |
|---|---|---|
| **Baseline (팀 공통 전처리)** | 40 | **0.88266** 최종 제출 |
| V2 (+ 상호작용·주기·플래그 피처) | 92 | 0.87189 |
| 확장 실험 ([01 노트북](notebooks/01_eda_preprocessing_modeling.ipynb), + EDA 플래그·One-Hot 상호작용 키) | 121 | 0.87416 |

**피처를 더 넣을수록 성능이 떨어진 이유**
1. 노이즈 피처가 기존 신호를 가림
2. 기존 피처와 강하게 겹치는 파생 피처로 인한 다중공선성
3. 피처 수 증가에 따른 과적합 위험
4. 상호작용 키(결제 방식 × 시간대 × 할인 구간)의 조합이 희소해짐

→ 같은 LightGBM, 같은 검증 방식에서 **검증 성능이 더 안정적인 Baseline 피처 셋**을 최종 선택

## 5. 결론 및 운영 제안

| 발견 | 제안 |
|---|---|
| **12시 전후 출고일 차이가 지연에 가장 크리티컬** | 12시 이전 접수 건 당일 출고 SLA 도입, 12~14시 접수 건은 익일 우선 출고 큐 분리, 오후 집중 시간대에 물류 인력 재배치 |
| 할인율이 높을수록 주문 폭주 → 지연 증가 | 대형 할인 이벤트 최소 2주 전 재고·출고 인력 증원, 할인 강도별 주문량 시뮬레이션으로 선제 배치 |
| 크리스마스·추수감사절 지연 집중 | 추수감사절 3주 전, 크리스마스 4주 전부터 배송 예상일 자동 완충, 지연 가능성 사전 고지로 클레임 예방, 연휴 직후 역물류 인력 증원 |
| 미국 내 타주 배송이 해외보다 더 지연 | 타주 배송 SLA를 주별 실제 평균 소요일 기준으로 1~2일 완충, 내륙 대형 주에 지역 풀필먼트 센터 확충 검토, 해외 배송의 넉넉한 SLA 방식 벤치마크 |

모두 **운영에서 예측하고 통제할 수 있는 변수**라는 점에서 실무 적용 가능성을 강조했습니다.

## 6. 개선 방향

- **피처 엔지니어링의 역설**: EDA에서 유의했던 패턴을 피처로 넣을수록 성능이 떨어졌습니다. 통계적 유의성과 모델 기여는 다르다는 점을 확인하였습니다.
- **실험 데이터 통일**: 모델 비교와 피처 셋 실험을 서로 다른 전처리 데이터로 진행했습니다. 다음에는 데이터를 하나로 고정한 뒤 모델과 피처를 비교하려고 합니다.
